# CS 220 — Computer Organization

A collection of programming exercises and assignments completed for CS 220: Computer Organization at St. Lawrence University.

## Overview

This repository contains coursework exploring the organization, architecture, and security of modern computer systems. Topics include low-level programming in C and ARM64 Assembly, code and data representations, secure and defensive coding, and computer architecture concepts such as CPU organization, caches, and the memory hierarchy.

## Topics Covered

- **C Programming:** Arrays, pointers, strings, structures, and dynamic memory allocation
- **Assembly Programming:** ARM64 instructions, branching, recursion, register management, and stack operations
- **Computer Architecture:** CPU organization, caches, memory hierarchy, and matrix memory-access patterns
- **Data Representation:** Binary representations and numerical operations
- **Computer Security:** Memory-safety concepts and security-related programming exercises

## Selected Implementations

- **Recursive Exponentiation:** Implemented integer exponentiation algorithms in both C and ARM64 Assembly.
- **Matrix Operations:** Implemented matrix scaling using Assembly instructions and pointer arithmetic.
- **Memory Access Patterns:** Explored row-major and column-major matrix traversal in C.
- **Pointer and Memory Management:** Practiced dynamic allocation, structures, and pointer-based data manipulation.
