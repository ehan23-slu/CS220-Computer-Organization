# CS 220 — Computer Organization

A collection of programming exercises and assignments completed for CS 220: Computer Organization at St. Lawrence University.

## Overview

This repository contains coursework exploring the organization, architecture, and security of modern computer systems. Topics include low-level programming in C and Assembly, code and data representations, secure and defensive coding, and computer architecture concepts such as CPU organization, caches, and the memory hierarchy.

## Topics Covered

- **C Programming:** Arrays, pointers, strings, and memory-related operations
- **Assembly Programming:** Low-level instructions and code representation
- **Computer Architecture:** CPU organization, caches, and memory hierarchy
- **Data Representation:** Binary data and numerical representations
- **Computer Security:** Secure and defensive coding concepts

## Technologies

- C
- Assembly
- Python
- Makefiles

## Repository Structure

- `arrays/` — Array-related exercises
- `assembly/` — Assembly programming
- `binary/` — Binary representations and operations
- `caches/` — Cache-related exercises
- `pointers/` — Pointer exercises
- `strings/` — String manipulation

Additional files in the root directory contain individual programming exercises and assignments.
